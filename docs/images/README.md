# Screenshot provenance

The fourteen `<page>-<appearance>.png` images show Vellora 0.2.20, captured on
October 4, 2026 at 1240 x 1000 pixels. Pages: `dashboard`, `history`, `models`,
`settings`, `appearance`, `help`, and `setup`; appearances: `notebook` and `classic`.

These are renders of the actual React interface with a mocked Tauri backend in
an isolated browser profile. All transcripts, statistics, charts, cost estimates
and saved-key status are synthetic. No actual API key, personal transcript,
device name, private account identifier or local file path is shown. Help & About
includes the project's intended public author/license attribution and repository
name. The running Windows app's data was not accessed, and no recording or
OpenAI request was made.

Each image was visually inspected before adding it. The PNGs are unedited
browser captures with no embedded EXIF, XMP, comments or other metadata.
`notebook.png` and `classic.png` are byte-for-byte aliases of the current
`appearance-notebook.png` and `appearance-classic.png` previews, respectively.
All sixteen screenshot files were refreshed together, replacing the earlier
branding. See [artwork provenance](../ARTWORK_PROVENANCE.md) for the new mark's
generation and review history.

See [GUI testing](../GUI_TESTING.md) for automated checks and their limits.
