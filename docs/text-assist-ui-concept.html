A · Quick Polish (tap Shift+Win): box + progress ring, no window takes focus

The outline uses the model's color. The ring fills as the corrected text streams in, measured against the length of your selection, and spins while the model is still thinking. Then the text is replaced in place, the ring turns into ✓ and fades after about 2 s.

B · Rewrite panel (hold Shift+Win): the panel opens next to the box

One version per style. Pick a style with keys 1–5; Tab switches the model, R asks for another take, D toggles the diff. Enter returns focus to TeXstudio and replaces the selection.

C · Ensemble: one card per model and effort, each appearing as soon as it finishes

The outline mixes the colors of the participating models; each card shows the model, effort, how it is billed and how long it took. No merge step: you pick a card. A card that fails shows its own error and the others are unaffected.

D · Fallback when an app doesn't report where the selection is

We still have to measure what VS Code and TeXstudio report. If an app gives no selection rectangle, the same ring and label float at the text cursor (caret), or at the mouse pointer if the caret position isn't available either. Cards are placed the same way.
